# G-ventZ translation glossary (Change 3, D73)

Used for machine translation and by reviewers. One agreed word per term and language; the review
sheet flags any message that departs from it.

## Never translated
- **G-ventZ** (and the wordmark "G-vent**Z**"), **Paystack**, **Flutterwave**, **Apple Pay**, **Google Pay**, **Google**, **WhatsApp**, **QR**.
- Placeholders in braces (`{name}`, `{count}`), tag names (`<b>`, `<link>`), and ICU keywords
  (`plural`, `select`, `one`, `other`, `=0`).

## Terms
| English | Meaning |
|---|---|
| host | the person or business running an event |
| guest | someone who registers or buys a ticket |
| event | — |
| ticket / ticket type | a single admission / a kind of ticket with its own price (e.g. "VIP") |
| check-in / check in | admitting a guest at the door by scanning their QR ticket |
| registration | a guest's entry for a free event |
| order | one purchase of one or more tickets |
| payout / payout account | money paid to a host / the host's bank account for it |
| refund | money returned to a guest |
| two-step sign-in | MFA: a code from an authenticator app or a passkey after the email code |
| passkey | WebAuthn credential (keep the industry's usual word per language) |
| dashboard | the host's area for their events |
| discover | the public list of events |
| waiting list | guests waiting for a place to free up |

## Style
- Address the reader informally where the language usually does on consumer apps (tu in French and
  Spanish is too familiar: use **vous** / **usted**; German **du** is common in consumer apps but use
  **Sie** for G-ventZ; Portuguese (Brazil) **você**).
- Keep sentences short, as the English is.
- **Arrows in text** ("← Previous", "Next →") point the other way in Arabic ("→ السابق", "التالي ←").
- Dates, times, numbers and prices are formatted by the app; never write them into a message.
